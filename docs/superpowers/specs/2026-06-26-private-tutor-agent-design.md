# 私人教师 Agent 设计规格

日期：2026-06-26

## 目标

开发一个面向单个初中学生的 Web 私人教师 Agent。学生上传试卷或习题照片后，系统识别错题，分析知识漏洞，用温和鼓励且面向提分的方式讲解知识点，并自动沉淀错题、母题、薄弱知识点和期末复习知识树。

首版覆盖初中全学科，重点不是做班级管理或完整教务系统，而是跑通“上传错题照片 -> AI 辅导讲解 -> 错题沉淀 -> 知识漏洞记忆 -> 期末知识树复习”的闭环。

## 用户与范围

### 用户

- 主要用户：一个初中学生。
- 辅助用户：家长可以查看错题本、知识漏洞和期末知识树，但首版不做独立家长账号。

### 学科范围

首版支持初中所有主要学科，包括语文、数学、英语、物理、化学、生物、历史、地理、道德与法治等。系统允许 AI 根据图片自动判断学科和年级；判断不确定时由用户手动选择。

### 不做的范围

- 多孩子档案与账号权限。
- 班级、教师端、学校管理。
- 支付、订阅、运营后台。
- 移动 App。
- 完整全国教材知识库。首版内置一套可扩展的初中学科知识点种子数据，后续逐步补齐。

## 产品体验

首屏采用“AI 老师对话”模式，而不是传统表格型错题本。学生打开 Web 应用后，看到的是一个可以上传照片并继续追问的 AI 私人教师。

核心体验：

1. 学生上传试卷或习题照片。
2. AI 识别题目、学生作答痕迹和可能错题。
3. AI 输出错因分析、知识点讲解、相似例子、母题总结和变式练习。
4. 学生可以继续追问，例如“为什么这里要设 x？”或“再给我讲简单一点”。
5. 系统在后台自动创建错题记录、更新知识漏洞、归纳母题类型。
6. 期末时，系统按年级和学科生成知识树，高亮薄弱知识点和高频母题漏洞。

AI 老师的表达风格为“温和鼓励 + 考试提分”：

- 先指出孩子已经做对或接近正确的地方。
- 再解释错因，避免批评式语言。
- 用初中生能理解的例子讲知识点。
- 总结考试中常见坑点、解题模板和提分策略。

## 页面结构

### AI 老师

首屏页面。用于上传照片、展示 AI 分析、继续追问。

主要模块：

- 图片上传区。
- 分析状态提示。
- 错题分析卡片。
- AI 对话区。
- 相似练习区。
- 保存到错题本的状态提示。

### 错题本

展示所有已登记错题。支持按学科、年级、时间、知识点、掌握状态筛选。

每条错题展示：

- 原图缩略图。
- 学科和年级。
- 知识点。
- 母题类型。
- 错因摘要。
- 掌握状态。
- 最近复习时间。

### 错题详情

展示单道错题的完整信息：

- 原始图片。
- OCR 或视觉模型识别出的题目文本。
- 学生错误答案或错误步骤。
- 正确答案与解题过程。
- 错因分析。
- 知识点讲解。
- 母题总结。
- 常见陷阱。
- 变式练习。
- 追问对话记录。

### 知识漏洞

按学科和年级展示薄弱知识点。每个漏洞记录：

- 关联知识点。
- 错误次数。
- 关联错题数量。
- 高频母题数量。
- 最近出现时间。
- 掌握程度。
- 复习建议。

### 期末知识树

知识树不做成一棵巨大的全学科树，而是按“年级 + 学科”拆分。

用户流程：

1. 选择年级：七年级、八年级、九年级。
2. 选择学科：语文、数学、英语、物理、化学、生物、历史、地理、道法等。
3. 查看该范围的独立知识树。
4. 点击薄弱节点查看关联错题、母题和复习建议。

知识树节点严重度：

- 普通节点：暂无明显漏洞。
- 普通薄弱：偶发错误。
- 重点薄弱：同一知识点多次错误。
- 高频母题漏洞：相同或类似母题反复出错，优先复习。

## 技术架构

采用单体 Web 应用，便于快速落地和本地演示。

推荐技术栈：

- Next.js：前端页面和后端 API。
- TypeScript：类型约束。
- SQLite：本地持久化。
- Prisma：数据建模与迁移。
- 本地上传目录：保存试卷和习题照片。
- 可替换 AI 分析器：真实 API 与模拟分析共用同一输出结构。

AI 模块采用双模式：

- 真实 API 模式：配置 API Key 后调用支持图像理解的大模型。
- 模拟模式：没有 API Key 或 API 调用失败时，使用内置示例生成结构化分析，保证演示和测试可跑通。

## 数据模型

### Student

首版只有一个学生，但保留学生字段，方便未来扩展多孩子档案。

字段示例：

- id
- name
- currentGrade
- createdAt
- updatedAt

字段示例：

- recognizedText

- grade
- questionType

- correctAnswer
- explanation
- mistakeReason
- masteryStatus
- createdAt

### KnowledgePoint

知识点，用于生成知识树。

字段示例：

- id
- subject
- grade
- name
- chapter
- parentId
- sortOrder

### KnowledgeGap

知识漏洞，记录孩子在某个知识点上的薄弱情况。

字段示例：

- id

- knowledgePointId
- errorCount

- repeatedArchetypeCount
- severity

- masteryLevel

字段示例：

- id
- subject
- grade
- knowledgePointId
- title
- pattern
- solutionTemplate
- commonTraps

### MistakeArchetype

字段示例：

- id
- mistakeId
- archetypeId
- similarityScore
- createdAt

### TutorMessage

围绕错题的追问对话。

字段示例：

- id
- mistakeId
- role
- content
- createdAt

### NonStudyRequestLog

记录被学习边界拦截的请求，用于家长了解使用情况。

字段示例：

- id
- studentId

该记录不做批评式展示，只做温和提醒和使用趋势参考。

## 知识漏洞与高频母题规则

系统不仅统计知识点错误次数，还要识别“相同或相似母题反复出错”。

规则：

1. 每道错题都尝试归入一个母题类型。
2. 如果母题已存在，则记录相似度并关联。
3. 如果相似母题在同一“学生 + 年级 + 学科 + 知识点”下多次出错，则提高漏洞严重度。
4. 严重度优先级为：高频母题漏洞 > 重点薄弱 > 普通薄弱 > 普通节点。
5. 高频母题漏洞在知识树中使用最强提醒样式。
6. 复习建议优先推荐高频母题，并生成变式练习。

建议阈值：

- 同一知识点错误 2 次及以上：普通薄弱。
- 同一知识点错误 3 次及以上：重点薄弱。
- 相同或相似母题错误 2 次及以上：高频母题漏洞。

阈值后续可配置。

## 学习用途限制

该 AI 助手只用于初中学习辅导。系统需要限制非学习用途，避免学生把它用于游戏、娱乐视频或无关闲聊。

允许的请求：

- 错题讲解。
- 知识点解释。
- 相似题练习。
- 学科内延伸问题。
- 复习计划。
- 学习方法建议。

拦截的请求：

- 游戏攻略。
- 娱乐视频推荐。
- 短视频内容。
- 与学习无关的闲聊。
- 诱导绕过学习限制的问题。

处理方式：

1. 请求进入 AI 之前先做学习意图分类。
2. 非学习请求不发送给通用回答流程。
3. 用温和语言拒绝，并把孩子引导回学习任务。
4. 记录拦截摘要和类别，用于家长查看趋势。

示例回复：

> 我主要帮你学习，这个游戏相关内容我不能帮你查。我们可以先把刚才那道题的关键步骤讲完，或者我给你出一道类似题练练。

## 异常处理

- 照片不清晰：提示重新上传，并保留原图。
- AI 无法判断学科或年级：让用户手动选择后重新分析。
- 识别出多道错题：生成多条候选记录，允许用户确认。
- API 不可用：自动切换到模拟分析，并在界面标记为演示结果。
- 知识点匹配不确定：挂到“待确认知识点”，不污染正式知识树。
- 母题相似度低：创建新的候选母题，并允许后续合并。

## 测试策略

首版测试重点：

- 无 API Key 时，模拟分析能完整跑通。
- 上传照片后能生成错题记录。
- AI 分析结果能写入错题、知识点、母题和知识漏洞。
- 相同或类似母题反复出错后，漏洞严重度升级为高频母题漏洞。
- 知识树按“年级 + 学科”生成，不混成一棵大树。
- 知识树能正确高亮普通薄弱、重点薄弱和高频母题漏洞。
- 非学习请求会被拦截，并返回温和引导。
- API 失败时能降级到模拟模式。

## 验收标准

首版完成后，应满足：

1. 学生可以在 Web 页面上传错题照片。
2. 没有 API Key 时，系统仍能用模拟分析生成完整辅导内容。
3. 配置 API Key 后，可以切换到真实图像分析。
4. 学生可以围绕错题继续追问。
5. 错题会自动保存到错题本。
6. 系统能记录知识漏洞和母题类型。
7. 相似母题多次出错会被重点标记。
8. 期末知识树按年级和学科拆分展示。
9. 非学习请求会被温和拦截。
